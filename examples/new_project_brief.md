# 공백 정리 함수

Python 표준 라이브러리만 사용하는 작은 라이브러리를 만들어 주세요.
하나의 기능은 문자열의 공백을 정리하는 것입니다.

공개 함수는 `src.app.normalize_spaces(text: str) -> str`입니다.
문자열 앞뒤의 공백을 제거하고, 연속된 공백·탭·줄바꿈을 ASCII 공백 한 칸으로 바꿉니다.
단어의 대소문자와 한글 등 공백 이외의 문자는 그대로 유지합니다.

예를 들어 다음과 같이 동작해야 합니다.

- `"  Hello   world  "` → `"Hello world"`
- `"안녕\t\tPython\n세계"` → `"안녕 Python 세계"`
- 빈 문자열이나 공백·탭·줄바꿈만 있는 문자열 → 빈 문자열
- 이미 정리된 `"Keep CASE 한글"` → 입력과 동일한 문자열

호출자가 `text`가 문자열임을 보장합니다. 타입 검증, 파일 입출력, 웹 서비스,
명령행 UI, 외부 패키지는 범위에 포함하지 않습니다.
이 기능을 하나의 요구사항과 여러 비즈니스 시나리오로 정리해 주세요.
